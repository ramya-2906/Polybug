
# 🪲 PolyBug - AI Code Debugger

PolyBug is a fast, multi-language AI code debugger powered by Google Gemini.

Paste your code, select language, and get instant bug analysis in Telugu + English mix.

**Live Demo:** `https://polybug-ai.streamlit.app/
`

### ✨ Features
- 🌍 Supports Python, Java, C++, JavaScript, SQL & more
- ⚡ Super fast analysis with `gemini-3.5-flash-lite` (1000 req/day)
- 🎯 Error Detection + Fixed Code + Explanation
- 🎨 Modern UI with custom CSS

### 🛠️ Tech Stack
- Streamlit
- Google Gemini API (`gemini-3.5-flash-lite` for free tier, `gemini-3.6-flash` for Pro)
- Python
